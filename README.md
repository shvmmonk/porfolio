## 🏗️ Overview

A creative developer portfolio built with **pure HTML, CSS & JavaScript** — no frameworks, no libraries. Inspired by the Minecraft aesthetic, this portfolio turns your typical boring "About Me" page into an interactive pixel-art adventure.

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| 🎨 **Pixel Art UI** | Hand-crafted pixel-style interface elements |
| ⚔️ **Hotbar Skill Inventory** | Skills displayed like a Minecraft hotbar |
| 🗃️ **Loot Chest Projects** | Projects hidden inside animated chests |
| 🔨 **Crafting Table Contact** | Contact form styled as a crafting table |
| 🔥 **Flickering Torches** | Animated torch lighting effects |
| ✨ **Particle Effects** | Floating particle animations throughout |

---

## 🛠️ Built With

- **HTML5** — Semantic structure & accessibility
- **CSS3** — Animations, transitions, pixel-art styling
- **JavaScript** — Interactive elements & DOM manipulation
- **GitHub Pages** — Free static hosting & deployment
